# Calculus and ODE User Guide

`MatCal::Calculus` covers finite differences and classical numerical
integration. Callers should provide finite inputs and explicit step/tolerance
options.

`MatCal::ODE` covers Euler and RK4 helpers. RK4 is shared between modern APIs
and the legacy PT-facing `RK4::step` / `step2` facade.
